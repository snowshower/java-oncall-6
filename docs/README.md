### 1. input
- 월과 시작 요일 입력(쉼표로 구분)
- 평일 순번 사원 닉네임 입력(쉼표로 구분)
- 휴일 순번 사원 닉네임 입력(쉼표로 구분)

### 2. output
- 순번 정보 출력
- 형식: 월 일 요일 닉네임

### 3. 사원 관리
- 사원 리스트
- 인덱스
- getter
- 인덱스에 해당하는 사원 얻는 메소드
- 다음 인덱스 얻는 메소드

### 4. 월 - enum
- 월
- 최대 며칠
- getter
- from

### 5. 요일 - enum
- 월,화,수,목,금,토,일
- 다음 요일 반환하는 메소드
- 평일인지 휴일인지 확인하는 메소드

### 6. 공휴일 - enum
- 월, 일
- 1월1일
- 3월1일
- 5월5일
- 6월6일
- 8월15일
- 10월3일
- 10월9일
- 12월25일

### 7. 달력
- 월 리스트?

### 8. 서비스
- 최종 출력용 순번 리스트 생성
- 최종 순번 리스트에 사원 추가

### 9. 예외처리
**1. 월 입력 예외**

**2. 요일 입력 예외**

**3. 사원 입력 예외**
- 닉네임 중복
- 닉네임 5자 초과
- 사원 5명 미만
- 사원 35명 초과


흐름
- 월, 요일 입력
- 해당 달력 생성
- 평일 순번 입력
- 휴일 순번 입력
- 평일, 휴일 사원 리스트 생성
- 최종 리스트에 사원 추가
  - 날짜 확인
    - 평일인지, 휴일인지
    - 평일 -> 평일 순번 해당 인덱스 사원 하나 꺼내서 최종 리스트에 추가
    - 휴일 -> 휴일 순번 해당 인덱스 사원 하나 꺼내서 최종 리스트에 추가
- 최종 리스트 돌면서 사원 이름 연속되면 그 다음 사원과 변경

### 1. input
- 월과 시작 요일 입력(쉼표로 구분)
- 평일 순번 사원 닉네임 입력(쉼표로 구분)
- 휴일 순번 사원 닉네임 입력(쉼표로 구분)

### 2. output
- 순번 정보 출력
- 형식: 월 일 요일 닉네임

### 3. 사원 관리
- 사원 리스트
- 인덱스
- getter
- 인덱스에 해당하는 사원 얻는 메소드
- 다음 인덱스 얻는 메소드

### 4. 날짜
- 일
- 요일
- 평일인지 휴일인지 확인하는 메소드

### 5. 달력
- 날짜 리스트

### 6. 서비스
- 최종 출력용 순번 리스트 생성
- 최종 순번 리스트에 사원 추가



흐름
- 월, 요일 입력
- 해당 달력 생성
- 평일 순번 입력
- 휴일 순번 입력
- 평일, 휴일 사원 리스트 생성
- 최종 리스트에 사원 추가
  - 날짜 확인
    - 평일인지, 휴일인지
    - 평일 -> 평일 순번 해당 인덱스 사원 하나 꺼내서 최종 리스트에 추가
    - 휴일 -> 휴일 순번 해당 인덱스 사원 하나 꺼내서 최종 리스트에 추가
- 최종 리스트 돌면서 사원 이름 연속되면 그 다음 사원과 변경
